critic-loop

Paste a paragraph. A critic reads it, says what is wrong and where, and the paragraph is rewritten. Three passes, every intermediate state shown.

The default engine is a deterministic rule-based critic running in your browser. No model, no network, no key. Same paragraph in, same critique out, every time. Live mode below swaps in a real model if you bring your own Anthropic key.
